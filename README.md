* Characters — キャラクター設定

* キャラクター一覧 → [Characters/INDEX.md](Characters/INDEX.md)

## Canon

Characters と World は本設定です。

Sample 内の IF 設定は、本設定とは異なる可能性を描いた派生・参考資料です。
IF 設定は本設定を上書きするものではなく、それぞれ独立したパラレルとして扱います。
